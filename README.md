# Сервис напоминаний

Консольный сервис для формирования напоминаний о личных, учебных и рабочих
делах. Проект развивает сценарий ПР1: статус, категория и текст напоминания
теперь применяются к коллекции записей, которая сохраняется между запусками.

## Реализованные функции ПР2

- просмотр всех напоминаний и определение их статуса по дате и времени;
- добавление и отмена напоминаний;
- поиск по тексту, фильтрация по категории и статусу, сортировка по дате;
- вывод статистики по категориям и статусам;
- проверка пользовательского ввода и обработка ошибок JSON-файла;
- загрузка данных при запуске и сохранение изменений в JSON.

Сценарий ПР1 сохранён в модуле `reminders.py`: функции определяют статус,
сообщение категории и форматируют напоминание. В ПР2 статус используется при
выводе, фильтрации и расчёте статистики.

## Структура проекта

```text
.
├── main.py                 # консольное меню и точка запуска
├── reminders.py            # обработка напоминаний и логика ПР1
├── storage.py              # загрузка и сохранение JSON
├── utils.py                # безопасный ввод из консоли
├── data/reminders.json     # данные напоминаний
├── tests/                  # тесты бизнес-логики и хранилища
├── requirements.txt        # pytest и flake8
└── .flake8                 # настройки линтера
```

## Формат JSON

Файл `data/reminders.json` содержит список словарей. В каждой записи обязательны
поля `id`, `text`, `category` и `remind_at`; категория может быть `учёба`,
`работа` или `личное`. Дата и время хранятся в формате ISO 8601
`ГГГГ-ММ-ДДTЧЧ:ММ`.

```json
[
    {
        "id": 1,
        "text": "Подготовить домашнее задание",
        "category": "учёба",
        "remind_at": "2026-09-25T14:30"
    }
]
```

## Требования

- Python 3.10 или новее;
- зависимости из `requirements.txt` (`pytest`, `flake8`).

## Установка

Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
```

В Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск приложения

```bash
python main.py
```

## Проверки

Запуск тестов:

```bash
python -m pytest
```

Проверка стиля:

```bash
python -m flake8 .
```

## Пример использования

```text
Выберите пункт меню: 2
Введите текст: Подготовить домашнее задание
Введите категорию: учёба
Введите дату и время (ДД.ММ.ГГГГ ЧЧ:ММ): 25.09.2026 14:30
Напоминание с ID 1 добавлено.
```

После добавления запись сохраняется в `data/reminders.json`; при следующем
запуске приложение загрузит её автоматически.
