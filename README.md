# Сервис напоминаний

Консольное приложение для личных, учебных и рабочих напоминаний.

## ООП-модель

Единственная предметная сущность — `Reminder`. Объект хранит `id`, `text`,
`category` и `remind_at` (`datetime`). Класс проверяет данные при создании и
предоставляет методы `get_status`, `matches_query`, `reschedule`, `format_for`,
`get_category_message` и `to_dict`. Связей между объектами нет; коллекции
приложения содержат `list[Reminder]`.

Функции в `reminders.py` выполняют операции над коллекциями: добавление,
отмену, поиск, фильтрацию, сортировку и статистику. Совместимые вспомогательные
функции статуса, категории и форматирования также сохранены.

## Хранение

В `data/reminders.json` сохраняется прежний список словарей. При загрузке
`storage.py` проверяет JSON и создаёт объекты `Reminder`; перед сохранением
вызывает `to_dict`. Время в файле имеет формат `ГГГГ-ММ-ДДTЧЧ:ММ`.

```json
[
    {
        "id": 1,
        "text": "Подготовить домашнее задание",
        "category": "учёба",
        "remind_at": "2026-09-25T14:30"
    }
]
```

## Структура

```text
main.py                 # консольное меню
reminders.py            # класс Reminder и бизнес-логика
storage.py              # JSON ↔ объекты
utils.py                # безопасный ввод
data/reminders.json     # данные
tests/                  # тесты
```

## Запуск и проверки

Требуется Python 3.10+ и зависимости из `requirements.txt`.

```bash
python main.py
python -m pytest -v
python -m flake8 .
```
