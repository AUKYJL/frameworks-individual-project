# Сервис напоминаний

## Назначение

Сервис помогает пользователям не забывать о важных делах, событиях и задачах, формируя понятные напоминания в нужное время.

## Целевая аудитория

Сервис предназначен для людей, которым нужно планировать личные дела, учёбу, работу и повседневные задачи.

## Предметная область

Пользователь создаёт напоминания, указывает их категорию и время. Сервис определяет актуальность напоминания и формирует сообщение для пользователя.

## Основные сущности

- **Пользователь** — человек, который использует сервис и получает напоминания.
- **Напоминание** — информация о задаче или событии, о котором необходимо напомнить.
- **Категория** — тип напоминания, например личное, учебное или рабочее.
- **Время напоминания** — момент, когда напоминание должно быть показано пользователю.

На этапе ПР1 эти сущности существуют только как описание будущей предметной модели и не реализуются в коде.

## Основные функции

1. Определение статуса напоминания по времени: «ещё не наступило», «актуально» или «просрочено».
2. Определение сообщения в зависимости от категории напоминания.
3. Формирование текста напоминания для пользователя из имени пользователя, текста задачи и времени.

Эти функции могут быть реализованы в `main.py` средствами базового Python без классов, списков, словарей, циклов, баз данных и сторонних библиотек.

## План развития

На следующих этапах проект будет постепенно расширен более сложной структурой Python-кода, веб-приложением на Django и базой данных. Также планируется добавить пользователей и аутентификацию, CRUD для напоминаний, REST API, Docker и CI/CD. На текущем этапе эти возможности не реализованы.
